licenses

List Licenses

Returns only currently-offered licenses, ordered for display. A retired license is omitted here but still resolves via GET /v1/licenses/{id} (410, not 404).

Responses

Get License

Returns one license's full metadata and verbatim body. 404 means this id was never registered; 410 means it was registered but is retired — see that response's own description for what retired means for existing drafts.

path Parameters
license_id
required
string (License Id)

Responses

/v1/licenses/{license_id}

Full conversation history, client-supplied. May be empty on the first turn.

Current draft state, client-supplied. May be null on the first turn.

The new user message. Required, non-empty.
